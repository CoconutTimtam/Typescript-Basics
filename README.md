# TypeScript Basics

**Deadly Coders x CBA — Code-Along Exercises**

Welcome! In this session, you'll learn the basics of TypeScript by writing, running and testing your own code.

## 1. Getting Started

### Prerequisites

Make sure you have installed:

* Visual Studio Code
* Node.js (LTS version)
* Git for Windows
* A GitHub account

### Install Dependencies

Open the project folder in VS Code and open a terminal (**Terminal → New Terminal**).

Run:

```bash
npm install
```

This installs the dependencies required for the project.

## 2. Running Your Code

Your TypeScript code is in:

`src/index.ts`

You'll write your examples in this file throughout the session.

### Compile your TypeScript

```bash
npm run build
```

This compiles your TypeScript code into JavaScript in the `dist` folder.

### Run your program

```bash
npm start
```

The output will appear in the terminal.

**Remember:** After changing your code, run the build command again before running the program.

## 3. What You'll Learn

During this session, you'll practise:

1. **Basic types:** `boolean`, `number` and `string`
2. **Variable declaration:** `let` and `const`
3. **Variable naming:** naming rules and camelCase conventions
4. **Functions:** parameters, return values and type annotations
5. **Arrow functions:** writing functions using arrow syntax
6. **Coding challenge:** combining these concepts in a small program

Follow the instructor's demonstrations and write the examples yourself in `src/index.ts`.

## 4. Saving Your Work to GitHub

Your work should be committed and pushed to your own GitHub repository.

After completing an exercise, open the VS Code terminal and run:

```bash
git add .
git commit -m "Describe what you completed"
git push
```

Use a meaningful commit message, such as:

* `Add basic TypeScript types`
* `Add variable declaration examples`
* `Add functions and type annotations`

A **commit** saves a snapshot of your work locally. A **push** uploads your committed changes to GitHub.

## 5. Troubleshooting

### TypeScript compilation errors

Check that your code matches the instructor's example. Pay attention to spelling, quotation marks, brackets and semicolons.

### `npm` or `node` is not recognised

Check that Node.js is installed. Close and reopen VS Code after installation, then try again.

### Git push fails

Check that you're signed in to the correct GitHub account and that your local repository is connected to your own GitHub repository.
